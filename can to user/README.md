# CAN log decoder

Запуск:

```powershell
py "can to user\main.py"
```

Скрипт просит выбрать один или несколько файлов `.csv`, `.xlsx`, `.xls` или `.xlsm`, затем JSON-шаблон из папки `templates` и путь для итогового Excel.

После выбора шаблона появляется окно выбора сигналов. Для МИД оно сделано таблицей как в CAN-анализаторе: строки - цилиндры, столбцы - детонация, смещение и ошибки. Для остальных шаблонов остается обычный список. По умолчанию галочки сняты: отметьте только нужные значения, чтобы не раздувать Excel-файл лишними колонками.

Затем выбирается режим времени:

- `Относительно 0`: первый столбец `TimeSec`, секунды от начала лога с миллисекундами, например `0.668`;
- `Абсолютное`: первый столбец `Time`, время сообщения из лога в формате `09:05:52.668`.

По умолчанию для регулятора газа используется относительное время, для МИД - абсолютное.

Поддерживаются два основных входных формата:

- новый CSV логгера: `CAN_ID_Hex`, `Data_Hex`, `Channel`, `Wall_Time`;
- старый формат регулятора, где в колонке `Data` первым байтом лежит PID, а последние 4 байта являются `float32`.

В итоговом `.xlsx` создается лист:

- `data`: широкая таблица `TimeSec` или `Time` + выбранные сигналы.

Без окон можно запустить так:

```powershell
py "can to user\main.py" "путь\к\can_messages.csv" -t "templates\gas_regulator.json" -s PV,SP,CV --time-mode relative -o "decoded.xlsx"
```

Для МИД с абсолютным временем:

```powershell
py "can to user\main.py" "путь\к\can_messages.csv" -t "templates\mid.json" -s "A1 Детонация,A2 Детонация" --time-mode absolute -o "mid_decoded.xlsx"
```

Посмотреть имена сигналов шаблона:

```powershell
py "can to user\main.py" --list-signals -t "templates\gas_regulator.json"
```
